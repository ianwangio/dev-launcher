## 菜单栏与系统行为

- App 使用深色圆角底、白色闪电和绿色能量环的独立图标；Release 构建由 1024 px 源图生成 16–1024 px 完整 `.icns`，Finder 与 Dock 均通过 bundle 元数据读取。
- 状态项提供“监听中/已暂停”VoiceOver label；暂停期间显示剩余时间或“直到手动恢复”。
- 菜单包含暂停 10 分钟、1 小时、直到手动恢复、立即恢复、开机启动、Dock 图标、打开窗口和退出。
- 开机启动通过 `SMAppService.mainApp` 注册；实机切换收到 macOS 登录项成功通知，并已恢复测试前的关闭状态。
- Dock 图标可以隐藏；隐藏后状态菜单仍存在并能重新打开主窗口。测试后已恢复为显示。
- 侧栏支持 `⌘1` 到 `⌘5`，应用菜单的“显示”菜单提供等价入口。
- 主页面保持挂载，仅切换可见性和交互命中；连续切换规则、集成、浮层、监听、活动后，规则编辑状态保持不变。
- 左侧未选中菜单在指针悬浮时显示统一的圆角弱高亮；已选中菜单继续使用强调色，重复点击当前菜单不触发更新。
- 窗口右上角使用紧凑的“状态文字 + 30 × 17 开关”，保留 14 pt 右侧安全间距；点击可暂停或恢复监听。
- “忽略的应用”通过原生文件面板从 `/Applications` 一次选择一个或多个应用；加入后以列表展示图标、名称和 Bundle ID，行首复选框只控制是否启用忽略，删除使用独立按钮，不再提供手动输入 Bundle ID。
- 五张浮层位置卡片均显式使用完整矩形命中区域；预览图、标题和卡片留白处都能完成选择。

## 明暗模式与可访问性

- 深色和浅色模式均完成 1280 × 760 截图检查；系统材质、文本、分隔线、强调色和禁用态均可读。检查后恢复用户原有深色模式。

## 下一轮：活动、统计与 GitHub 性能

### 活动保留条数

- 活动页标题区提供“最多保留”设置，固定选项为 100、500、1000、2000、5000，默认及旧配置迁移值为 1000。
- 调低上限后立即只保留最新 N 条并保存；后续新增记录持续遵守该上限。调高上限不会恢复已裁剪的记录。
- 上限保存在设置文件，活动文件继续只包含时间、规则、动作和结果白名单字段。

### 统计页面

- 侧栏在“活动”后增加“统计”，支持按日和按月切换。
- 页面展示当前保留范围内的总执行、成功和失败摘要；每个时间桶展示总次数、成功、失败和成功率，并按时间倒序。
- 聚合使用本机 Calendar 和时区，只读取活动白名单字段，不增加统计数据文件或敏感字段；无记录时展示空状态。

### GitHub 滚动性能

- 相同仓库快照、账号、Organization 和搜索条件下，完整仓库投影只允许计算一次。
- 滚动创建仓库行时只读取稳定数组，不得重新执行账号/组织/仓库过滤、Set 构造或排序。
- 优化前建立可重复运行的性能反馈环；逐个修复已确认热点，并持续验证账号和 Organization 复选、更新时间排序、搜索、默认最近 10 个及仓库勾选语义不变。

### 顺序验收

1. 先验收活动容量静态原型，再验收真实 Release 控件。
2. 再验收统计页静态原型和真实 Release 页面。
3. 最后查看 GitHub 性能反馈环、逐项优化证据并验收真实滚动。
