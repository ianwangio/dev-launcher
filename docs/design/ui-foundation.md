# DevLauncher UI Foundation

本规范来自节点 2 的实机截图审计。所有后续页面复用这些 token 和组件，不在页面里重新决定同类控件尺寸。

## 基础网格

| 名称 | 值 | 用途 |
|---|---:|---|
| `xSmall` | 4 pt | 标题与说明、图标与短标签 |
| `small` | 8 pt | 同一控件组内部 |
| `medium` | 12 pt | 表单行与相邻控件 |
| `large` | 16 pt | 列表内容边距 |
| `xLarge` | 24 pt | 页面 section 间距 |

所有尺寸落在 4 pt 网格；不再出现 5、7、9、11 pt 的临时间距。

## 控件尺寸

| 控件 | 规格 |
|---|---:|
| 表单控件与带标签开关 | 高 32 pt |
| 辅助选项行 | 高 24 pt |
| 图标按钮与更多菜单点击区 | 28 × 28 pt |
| 开关槽位 | 40 × 24 pt，统一 `.small` |
| 规则图标 | 36 × 36 pt |
| 规则行 | 最小高 56 pt |

列表、详情 header、设置页必须使用同一个 `UIEnableToggle`，不允许直接声明 `.switch` 或 `.mini`。

#### 表单列

条件行固定三列：

1. 字段：160 pt；
2. 操作符：132 pt；
3. 值：填满剩余宽度。

删除按钮单独占 28 pt。组合方式行使用同一字段列放标签，分段控件从操作符列开始；辅助项行与值列左边缘对齐，
高度固定 24 pt。嵌套组只增加 16 pt 左缩进，不改变列宽。

## 通用组件

- `UIEnableToggle`：列表、详情 header 与设置统一开关。
- `UIOverflowMenu`：统一 28 pt 点击区并隐藏系统额外下拉箭头。
- `UIIconButton`：删除、增加、刷新等纯图标操作。
- `UISectionHeading`：section 标题与说明。
- `UIControlLabel`：固定宽度表单标签。
- `UICheckbox`：统一辅助行高度与字号。

## 使用规则

- 页面只能组合 Foundation 组件；控件尺寸不随页面语义变化。
- 同一层级使用同一字号，状态颜色不替代文字标签。
- 省略号只表示操作菜单，不同时显示下拉箭头。
- 行内辅助选项不悬空，必须落在对应主字段下方的统一基线。
- 新页面进入实现前先列出它使用的 Foundation 组件，缺少的组件先在 Foundation 中设计。
